# Pre-registration: Price clustering (ผลของเลขกลม) ต่อคู่/คี่ของราคาปิด

เขียนเมื่อ 2026-10-14 **ก่อน** ดูผลบนข้อมูลทดสอบ ห้ามแก้ไฟล์นี้หลังจากรันการทดสอบ

## ที่มา (ขั้นหาไอเดีย)
- ข้อมูลหาไอเดีย: 2016-08-29 ถึง 2025-09-06 (ก่อนช่วงข้อมูลของโจทย์), หุ้นละ 2,196 วัน
- ADVANC: ถ้าราคาปิดเมื่อวาน (ส่วนจำนวนเต็ม) ลงท้ายด้วย 0 -> วันนี้ปิดเลขคู่ 58.2% (n=232, p=0.015)
  และ >= 50% ใน 7 จาก 10 ปี
- KBANK: ไม่พบรูปแบบเดียวกัน (49.0%, n=208)
- ข้อควรระวัง: ดูไป 20 กลุ่ม (2 หุ้น x เลขท้าย 10 ตัว) -> p=0.015 ไม่ผ่าน Bonferroni (0.0025) จึงต้องทดสอบยืนยัน

## ข้อมูลทดสอบ
2025-09-07 ถึงวันสุดท้ายในไฟล์ (2026-08-28) = ข้อมูลตามโจทย์ ยังไม่เคยใช้ดูรูปแบบนี้

## H1 (หลัก, กฎตายตัว ไม่มีการเทรน)
- กลุ่ม: ADVANC, วันที่ราคาปิดเมื่อวาน (floor) ลงท้ายด้วย 0
- ทำนาย: วันนี้ปิดเลขคู่
- ผ่าน: accuracy > 50% และ binomial one-sided p < 0.05
- หมายเหตุ: คาดว่ามีแค่ ~20-25 วันเข้าเงื่อนไข -> ถ้าผลจริงคือ 58% power มีแค่ ~20%
  ดังนั้น "ไม่ผ่าน" ไม่ได้แปลว่าไม่มีผลจริงเสมอไป แต่ "ผ่าน" จะเป็นหลักฐานที่ดี

## H2 (รอง, CNN+ANN ตามโจทย์)
- โมเดล `hybrid_round`: STFT spectrogram -> CNN, แล้วต่อ feature เสริมเข้า ANN
  = extras เดิม (คู่/คี่เมื่อวาน ฯลฯ) + one-hot เลขท้ายราคาปิดเมื่อวาน (10 ค่า) + ระยะห่างจากเลขลงท้าย 0
- ประเมินแบบเดิม: walk-forward 4x20 วัน + holdout 32 วัน/หุ้น, ทั้ง 2 หุ้น
- ผ่าน: holdout รวม (64 วัน) accuracy > 50% และ p < 0.05

## เพิ่มเติม (สำรวจ ไม่ใช่การยืนยัน)
- H1 กับ KBANK (คาดว่าไม่มีผล)
- `hybrid_round` บน 9 ปีก่อนหน้า -- ข้อมูลช่วงนี้ถูกใช้หาไอเดียแล้ว จึงใช้เป็นหลักฐานยืนยันไม่ได้
