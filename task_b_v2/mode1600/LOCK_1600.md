## 2. Protocol (PLAN_DRAFT ข้อ b, c · `locked1600.py`)

- target: `y = Close_official(t) / C15(t) − 1` · ราคาที่ทำนาย `C15 · (1 + ŷ)` · Naive: ŷ = 0
- feature: `r15`, `gap`, `range15`, `vol15` (นิยามใน `features1600.py` · แท่ง range = (10, 11, 12, 14, 15) · volume = (11, 12, 14, 15) · ตัวหาร vol = 20 eligible day ก่อนหน้า)
- walk-forward: ประเมิน **2024-10-01 → 2026-08-28** · เทรนใหม่ทุก **20** วันทำการ (ขอบบล็อกจากปฏิทินรายวัน ร่วมสองหุ้น) → **23 บล็อก**
  · train = ทุกแถวที่ใช้ได้ก่อนวันแรกของบล็อก · early stop + เลือก c = 15% ท้ายของ train · scaler/สเกลภาพ/normalize จาก 85% แรก
  · seeds 0–9 (10 ตัว) เฉลี่ยคำทำนาย · รายงานแยก 2024-10-01 → 2025-02-25 และ 2025-02-26 → 2026-08-28
- replay: เทรนครั้งเดียวด้วยแถว ≤ **2026-09-25** · ทำนาย 2026-09-28 → 2026-10-22 ทาง (i) ผลหลัก 17 วัน + ทาง (ii) ผลเสริม · ตาราง log ติดป้าย `bar_source` ต่อวัน
- ตัววัด: relMAE (return, บาท) · MAE/RMSE บาท · IC Pearson + Spearman (คงที่ → 0 · B39) · DirAcc · StdRatio (ธง) · DM vs Naive · c ∈ {0, 0.1, …, 1} (รายงานก่อน/หลังปรับ)
