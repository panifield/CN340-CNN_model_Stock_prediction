ภาพ spectrogram ที่โมเดลเห็น

Spectrogram ของวันคู่และวันคี่ดูไม่ต่างกัน ผลต่างเฉลี่ยของสองกลุ่ม (แถวล่าง) เกือบเป็นสีขาวทั้งภาพ

  • ภาพบน: ช่วงที่ราคาผันผวน (เช่น มี.ค.–เม.ย. 2569) เห็นเป็นแถบสว่างชัดเจน spectrogram จับความผันผวนได้ดี
  • ภาพล่าง: ภาพเฉลี่ยของวันคู่กับวันคี่แทบเหมือนกัน แปลว่าสิ่งที่ spectrogram เห็นไม่เกี่ยวกับคู่/คี่ เป็นสัญญาณแรกว่าโจทย์นี้อาจทายไม่ได้

วิเคราะห์ข้อมูล: ทำไมคู่/คี่รายวันเกือบสุ่ม

ราคาขยับเป็นเลขคู่ (คู่/คี่เหมือนเดิม) กับเลขคี่ (คู่/คี่สลับ) บ่อยพอ ๆ กัน คู่/คี่ของวันนี้จึงแทบไม่ขึ้นกับเมื่อวาน

  • ราคาไม่เปลี่ยนบ่อยที่สุด: ขยับ 0 บาท 20–22% ของวัน แต่ขยับ ±1 บาท (สลับ) รวมกันได้ประมาณ 32–33% ทำให้สองฝั่งหักล้างกัน
  • ผลรวม: โอกาสที่วันนี้คู่/คี่เหมือนเมื่อวานคือ 49.7% (KBANK) และ 51.2% (ADVANC) เกือบเท่าโยนเหรียญ
  • เช็คเพิ่ม: ต่อให้ใช้ราคาเปิดของวัน t ซึ่งรู้ก่อนตลาดปิด ก็ทายคู่/คี่ตอนปิดได้แค่ 48.8% (KBANK) และ 50.5% (ADVANC)
  • ข้อสรุป: ข้อมูลถึงเมื่อวานจึงทายไม่ได้ ไม่ว่าจะใช้โมเดลไหน (ยืนยันด้วยการทดลองในสไลด์ 8–9)

แก้ bug STFT และพิสูจน์ว่าโมเดลเรียนรู้ได้

ก่อนแก้ โมเดลแทบมองไม่เห็นข้อมูล 3 วันล่าสุด หลังแก้ โมเดลทายความผันผวนได้ 73–84% แต่คู่/คี่ยังเท่าการเดา

  • สาเหตุ: Hann window มีค่าเกือบ 0 ที่ขอบ ถ้าไม่ pad วันล่าสุดจะอยู่ที่ขอบของ frame สุดท้ายเสมอ
  • ตัวควบคุมบวก: ใช้ label ที่รู้ว่าทายได้จาก input จริง (ความผันผวน 5 วันล่าสุดสูงกว่า median) เพื่อพิสูจน์ว่า pipeline ทำงาน
  • ตัวควบคุมลบ: label สุ่ม ได้ 34–57% อยู่ในช่วงที่การเดาสุ่มทำได้ แปลว่าไม่มี leak
  • ข้อสรุป: ผลคู่/คี่ที่ได้ ~50% เป็นเพราะข้อมูลไม่มีรูปแบบให้เรียน ไม่ใช่เพราะโมเดลเสีย
สไลด์ 7

วิธีประเมินผลที่กันการ "ดวงดี"

ยิ่งลองหลายวิธี ยิ่งมีโอกาสเจอตัวเลขสวยโดยบังเอิญ จึงแยก "ข้อมูลที่ใช้เลือก" ออกจาก "ข้อมูลที่ใช้พิสูจน์" ทุกครั้ง

  • Walk-forward: เทรนด้วยข้อมูลก่อนช่วงทดสอบเท่านั้น และ retrain ทุก 20 วัน
  • Holdout: ข้อมูลช่วงท้ายที่ล็อกไว้ ใช้รายงานผลอย่างเดียว ไม่ใช้เลือกวิธี
  • Normalize: ใช้ค่าเฉลี่ยและ SD จาก train เท่านั้น
  • Bonferroni: ลอง k วิธี ต้องได้ p < 0.05/k
  • Replication: ทดสอบซ้ำบนปีอื่นที่ไม่เคยใช้เลือก
  • Pre-registration: เขียนสมมติฐานและเกณฑ์ลงไฟล์ก่อนดูผลทดสอบ

ไฟล์ล็อกสมมติฐาน: A/experiments/clustering/preregistration.md, A2/analysis/preregistration.md

Task A2: ตั้งค่าและวิเคราะห์ช่วงท้ายตลาด

หลัง 16:00 ราคาปิดเท่าเดิม 38–40% ของวัน และขยับ ±1 ช่วงราคาประมาณ 45% ที่เหลือ ผลต่อคู่/คี่ขึ้นกับว่าช่วงราคาเป็น 0.5 หรือ 1 บาท

  • ช่วงราคา 1 บาท (ราคา ≥ 200): ขยับ ±1 ช่วงราคา = ±1 บาท คู่/คี่สลับทุกครั้ง → ทายถูกแค่ 51.9%
  • ช่วงราคา 0.5 บาท (KBANK < 200): ขยับ ±0.5 บาทเปลี่ยนส่วนจำนวนเต็มแค่ครึ่งหนึ่งของกรณี (เช่น 162.0 → 162.5 ยังเป็น 162) → ทายถูก 64.3%
  • ข้อสรุป: สัญญาณที่ทายได้มาจากกลไกช่วงราคาของตลาด SET ไม่ได้มาจากรูปแบบราคา

วิเคราะห์เพิ่ม: threshold และ label แบบ ×2

ปรับ threshold หรือเปลี่ยน label ไม่ได้ทำให้ทายได้จริง ที่ดูดีขึ้นมาจากการมองย้อนหลังหรือคลาสไม่สมดุล

  • Threshold: มองย้อนหลังเพิ่มได้ 1–3% แต่เมื่อเลือก threshold จากครึ่งแรกตามเวลาแล้ววัดครึ่งหลัง ไม่ดีกว่า 0.5 เลย (A2 16:30: 53.3% เทียบกับ 56.1% ที่ 0.5) จึงใช้ 0.5 ต่อ
  • Label ×2: ADVANC ราคา ≥ 200 (ช่วงราคา 1 บาท) ปี 2566–2569 → label เป็น 0 เกือบทุกวัน (คี่ 0–3%)
  • accuracy ดูสูง 64–87% แต่ ต่ำกว่าการทายคลาสใหญ่ตลอดทุกกรณี และในวันช่วงราคา 0.5 บาทที่ label สมดุล ได้ 51.6% เทียบ 51.9%

คำถามคำตอบจากข้อมูล

ปรับ threshold / label ×2 / pretrain / Optuna ช่วยไหมไม่ช่วย ทุกวิธีกลับมาที่ ~50% บนข้อมูลที่ไม่เคยเห็น
